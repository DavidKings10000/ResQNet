# ResQNet User Manual

## Citizen
- Register an account and verify email
- Report emergencies with GPS, description, and media
- Track the status of submitted incidents

## Dispatcher
- Review incoming incidents and triage scores
- Assign responders and override AI recommendations when needed
- Monitor responder status and close incidents

## Hospital and Responders
- Receive incident alerts and update patient arrival status
- Provide ETA and condition updates to improve coordination
